# Personal Expense Calculator

## 📌 Project Description

The Personal Expense Calculator is a simple web application that helps users record, calculate, and manage their daily expenses. It provides an easy way to track income and expenses and understand overall spending.

## ✨ Features

- Add personal expenses
- Enter expense amount and description
- Select expense categories
- Calculate total expenses
- View expense details
- Simple and user-friendly interface
- Responsive design
- Easy expense tracking

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
